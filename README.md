# SK148 (Blue Sonic) Orientation Camp Memories
Storing stories, pictures, and memories P'เม่น and N'เม่น had from the camp. Will be maintained until at least year 2029.

## Getting Started
1. First, make sure you have `npm` or `bun` runtime installed.
2. Run `npm install` or `bun install` to install required packages.
3. Start the development server with `npm run dev` or `bun run dev`.

## Contribution
Though this project is not expected to be updated regularly, we're open to meaningful contributions; such as new 
memories, features, fixes, and enhancements. If you have anything to submit, open a `Pull Request (PR)` and we'll 
take a look at it. Please make sure your pull request explains your changes clearly with quality code/resources.

In case of no responses over `72 hours`, please reach out to [metawat.rojn@gmail.com](mailto:metawat.rojn@gmail.com) about your request.
